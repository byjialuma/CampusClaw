## Purpose

定义班级内多智能体（agents）实体与其技能/材料绑定：教师在同一班级维护多个面向不同场景的智能体，每个智能体独立持有提示词并绑定技能与材料；学生按会话选择智能体提问，默认使用教师最近更新的一个，且各班智能体互不可见。

## ADDED Requirements

### Requirement: 教师可在本班维护多个智能体

系统 MUST 为教师提供班级内多智能体的维护能力：新建、改名与改提示词、删除、列表查看。智能体归属班级 MUST 取自登录会话（JWT claims），MUST NOT 采用请求参数中的班级标识。同一班级内智能体名称 MUST 唯一，重名新建或改名 MUST 返回 HTTP 400。删除智能体时 MUST 同步解除其技能与材料绑定，MUST NOT 影响其他智能体的绑定。智能体管理接口 MUST 仅对教师角色开放：未登录调用 MUST 返回 HTTP 401，学生调用 MUST 返回 HTTP 403，跨班或不存在智能体的访问 MUST 返回 HTTP 404（与「无此数据」表现一致，不暴露存在性）。

#### Scenario: 教师新建智能体并出现在本班列表

- **WHEN** 教师在本班新建一个名称与提示词均合法的智能体
- **THEN** 系统返回成功，本班智能体列表中出现该智能体，其提示词为所填内容

#### Scenario: 同班重名被拒绝

- **WHEN** 教师在本班新建（或改名得到）与已有智能体同名的智能体
- **THEN** 系统返回 HTTP 400，原有智能体保持不变

#### Scenario: 删除智能体解除绑定

- **WHEN** 教师删除一个已绑定技能与材料的智能体
- **THEN** 该智能体从其班级列表移除，其绑定关系一并解除，其他智能体的绑定不受影响

#### Scenario: 未登录与学生调用被拒绝

- **WHEN** 未携带有效令牌调用智能体管理接口，或已登录学生调用同一接口
- **THEN** 前者返回 HTTP 401，后者返回 HTTP 403，均不读取或写入任何智能体数据

#### Scenario: 跨班访问他班智能体返回不存在

- **WHEN** 教师尝试读取、修改或删除不属于本班的智能体
- **THEN** 系统返回 HTTP 404，且不透露该智能体是否存在

### Requirement: 技能与材料必须绑定到智能体后才参与该智能体

系统 MUST 提供智能体与技能、智能体与材料的绑定维护能力（新增绑定、解除绑定、查看当前绑定）。只有同时满足「绑定到当前智能体」与「技能处于已启用状态」的技能才参与该智能体的提问处理；MUST NOT 因技能在本班存在或其适用条件命中而使其在未绑定时参与。回答时可召回的材料 MUST 限定为绑定到当前智能体的材料；该智能体没有绑定任何材料时，MUST NOT 使用本班其他材料召回。绑定与解绑接口 MUST 仅对教师角色开放；引用不存在、跨班或非本班的技能或材料时 MUST 返回 HTTP 404。绑定关系 MUST 按班级隔离。

#### Scenario: 绑定技能后参与该智能体

- **WHEN** 教师把一条已启用技能绑定到某智能体，随后学生对该智能体提问
- **THEN** 该技能进入该智能体的候选技能集，可被该轮路由命中

#### Scenario: 未绑定技能不参与

- **WHEN** 本班存在一条已启用且适用条件命中问题的技能，但它未绑定到当前智能体
- **THEN** 该技能不进入候选集，本轮不命中该技能，其工具也不被调用

#### Scenario: 召回限定在绑定材料内

- **WHEN** 某智能体只绑定了本班部分材料，学生就该智能体提问
- **THEN** 本轮召回的分片全部来自该智能体绑定的材料，不出现未绑定材料的分片

#### Scenario: 未绑定任何材料时不召回他班或他智能体材料

- **WHEN** 某智能体未绑定任何材料，学生对其提问
- **THEN** 本轮不召回本班其他材料，引用列表为空数组

#### Scenario: 绑定不存在或跨班的资源返回不存在

- **WHEN** 教师尝试绑定或解绑不属于本班的技能或材料
- **THEN** 系统返回 HTTP 404，绑定关系不发生变化

### Requirement: 会话创建时绑定智能体且会话内沿用

学生创建会话时 MUST 指定一个本班智能体，该会话 MUST 持久化记录其绑定的智能体；此后该会话内的每一轮提问 MUST 沿用该智能体，不允许在同一会话内切换智能体。会话绑定的智能体 MUST 来自本班；指定不存在或跨班的智能体时 MUST 返回 HTTP 404，MUST NOT 静默改绑到其他智能体。会话与其智能体绑定 MUST 仅对其所属学生可见。

#### Scenario: 新会话固定智能体

- **WHEN** 学生选择一个本班智能体创建会话
- **THEN** 该会话记录该智能体，后续该会话内的提问按该智能体处理

#### Scenario: 同一会话内沿用不切换

- **WHEN** 学生在某会话中连续追问多轮
- **THEN** 每轮均使用该会话创建时绑定的同一智能体，不因其他智能体更新而改变

#### Scenario: 指定不存在或跨班智能体被拒绝

- **WHEN** 学生创建会话时指定一个不属于本班或已删除的智能体
- **THEN** 系统返回 HTTP 404，不创建会话，也不改绑到其他智能体

### Requirement: 学生默认使用教师最近更新的智能体并可切换

学生进入解题助手时，系统 MUST 默认选中本班中「教师最近设计」的智能体，即按最近更新时间取最新的一个（更新时间相同时取编号较大者）。学生 MUST 能查看本班全部智能体并切换选择其他智能体，切换后的选择 MUST 用于其之后新建的会话。学生 MUST NOT 看到其他班级的智能体。本班不存在任何智能体时，前端 MUST 提示无可用智能体且 MUST NOT 允许发起提问。

#### Scenario: 默认选中最近更新的智能体

- **WHEN** 本班存在多个智能体，学生进入解题助手
- **THEN** 默认选中的是按最近更新时间最新的那一个

#### Scenario: 学生切换智能体后用于新会话

- **WHEN** 学生切换选择另一个本班智能体并新建会话
- **THEN** 该新会话绑定切换后的智能体

#### Scenario: 学生看不到他班智能体

- **WHEN** 学生查看可选智能体列表
- **THEN** 列表中只出现本班智能体，不出现其他班级的智能体

#### Scenario: 无智能体时不可提问

- **WHEN** 本班尚未创建任何智能体，学生进入解题助手
- **THEN** 界面提示无可用智能体，且不提供可用于提问的输入或以其余方式发起提问

### Requirement: 教师侧智能体管理入口与学生不可见

前端 MUST 为教师提供智能体管理入口：维护本班智能体（新建、改名与改提示词、删除）、为每个智能体绑定或解除技能与材料。学生视图 MUST NOT 出现智能体维护、技能/材料绑定等教师控件，学生只能查看并选择本班智能体。前端控件缺失 MUST NOT 是唯一防线：智能体与绑定管理接口 MUST 由服务端按角色强制校验。

#### Scenario: 教师完成智能体维护与绑定

- **WHEN** 教师新建一个智能体、填写提示词并绑定两条技能与一份材料
- **THEN** 界面上该智能体显示其提示词与已绑定的技能、材料清单

#### Scenario: 学生界面无管理控件且接口被拒

- **WHEN** 学生登录后浏览首页，并尝试直接调用智能体管理或绑定接口
- **THEN** 页面不出现相应控件，直接调接口时服务端返回 HTTP 403
