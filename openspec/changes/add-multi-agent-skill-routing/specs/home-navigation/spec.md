## ADDED Requirements

### Requirement: 教师首页标签中「智能体管理」取代「助手设置」

教师登录后首页 MUST 显示四个标签页：「学生名单」「本班资料」「智能体管理」「技能管理」。原「助手设置」标签 MUST 升级为「智能体管理」标签，MUST NOT 再以「助手设置」为名单独存在。每个标签页独占右侧主区域全高，切换时 MUST 保持左侧导航不变。「智能体管理」标签 MUST 展示本班智能体列表，并提供每个智能体的提示词维护与其技能、材料绑定。标签页 MUST 仅对教师角色可见；学生 MUST NOT 看到任何教师标签页。

#### Scenario: 教师切换四个标签页

- **WHEN** 教师登录后依次点击「学生名单」「本班资料」「智能体管理」「技能管理」
- **THEN** 右侧主区域分别显示对应内容（其中「智能体管理」展示本班智能体列表与其技能、材料绑定），切换时左侧导航保持不变

#### Scenario: 助手设置已升级为智能体管理

- **WHEN** 教师登录后查看其标签页
- **THEN** 页面上不出现名为「助手设置」的标签页，取而代之的是「智能体管理」标签页

#### Scenario: 学生看不到教师标签页

- **WHEN** 学生登录后查看首页
- **THEN** 页面不出现「学生名单」「智能体管理」「技能管理」标签页或入口

### Requirement: 学生首页侧栏新增智能体列表并默认选中最近更新的智能体

学生登录后首页 MUST 显示左侧导航栏（含「解题助手」「资料库」入口与本班智能体列表）与右侧主区域。右侧默认显示解题助手对话页（含欢迎语与输入框）。左侧导航 MUST 展示本班全部智能体供学生选择，且默认选中教师最近更新的一个智能体；切换所选智能体 MUST 影响学生之后新建的会话，MUST NOT 改变同一既有会话内已绑定的智能体。点击「资料库」后右侧切换到本班资料列表。左侧导航下方 MUST 显示历史会话列表，点击可切换到对应会话。

#### Scenario: 学生默认看到解题助手对话页并选中最近更新的智能体

- **WHEN** 学生登录后进入首页
- **THEN** 右侧默认显示解题助手对话页（含欢迎语与等待输入的聊天框），左侧智能体列表默认选中教师最近更新的那个智能体

#### Scenario: 学生切换智能体并新建会话

- **WHEN** 学生点击左侧智能体列表中的另一个本班智能体后发起新会话
- **THEN** 该新会话绑定切换后的智能体，既有会话的智能体绑定不变

#### Scenario: 学生切换到资料库

- **WHEN** 学生点击左侧导航的「资料库」
- **THEN** 右侧切换为本班资料列表，左侧导航、智能体列表与历史会话列表保持不变

#### Scenario: 学生从历史会话列表切换会话

- **WHEN** 学生点击左侧历史会话列表中的某条会话
- **THEN** 右侧切换为该会话的对话视图，加载历史消息，且左侧智能体选择显示为该会话绑定的智能体

#### Scenario: 本班无智能体时提示不可提问

- **WHEN** 本班尚未创建任何智能体，学生进入首页
- **THEN** 左侧智能体列表为空并提示无可用智能体，界面不提供可用于提问的输入
