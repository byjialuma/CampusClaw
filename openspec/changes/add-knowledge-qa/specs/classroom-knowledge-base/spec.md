## Purpose

在班级限定语义检索之上，提供基于大语言模型的知识问答能力：用户输入自然语言问题，系统召回本班材料片段并生成结构化回答，同时附带可溯源的引用来源。

## ADDED Requirements

### Requirement: 知识问答必须基于本班材料召回并生成回答

系统 MUST 提供受登录会话保护的知识问答能力。用户提交自然语言问题时，系统 MUST 先通过 Embedding 服务将问题向量化，再在向量库中以当前用户 `class_id` 为强制过滤条件召回最相关的材料分片。若召回分片非空，系统 MUST 调用 Chat Completions 接口，将问题与召回分片作为上下文，要求模型基于分片内容生成回答；若召回分片为空（无切片），系统 MUST NOT 调用 Chat Completions 接口，而是直接返回固定文案与空引用列表。系统 MUST NOT 使用外班分片生成回答，也 MUST NOT 在召回或生成阶段读取请求中的任何班级标识参数。

#### Scenario: A 班用户提问只基于 A 班材料回答

- **WHEN** A 班的学生或教师提交一个两班材料中均存在相近内容的问题
- **THEN** 系统召回的分片全部来自 A 班材料，生成的回答仅基于这些分片，不引用或暗示 B 班材料内容

#### Scenario: 伪造班级参数不影响问答范围

- **WHEN** 用户在问答请求中附加、篡改 `class_id`、`classId` 或其他班级标识参数
- **THEN** 系统忽略这些参数，仍仅按服务端会话中的班级过滤召回与生成

#### Scenario: 未登录调用问答接口被拒绝

- **WHEN** 未携带有效 JWT access token 调用问答接口
- **THEN** 系统返回 HTTP 401，响应体不包含任何分片、回答或材料数据

#### Scenario: 空问题或超长问题被拒绝

- **WHEN** 已登录用户提交空字符串（或仅空白字符）或超过 500 字的问题
- **THEN** 系统返回 HTTP 400 且不调用 Embedding、向量检索或 LLM 接口

### Requirement: 问答必须调用两次大模型接口

系统 MUST 按以下顺序执行问答流程：第一次调用 Embedding 接口将用户问题向量化；第二次调用 Chat Completions 接口，将问题与召回的分片文本作为上下文，要求模型生成自然语言回答。若召回分片为空（无切片），系统 MUST NOT 执行第二次调用（Chat Completions），而是直接返回固定文案「根据已有材料无法回答该问题」与空引用列表。两次调用 MUST 使用各自独立的配置（Embedding 使用 `EMBEDDING_*` 变量，Chat 使用 `LLM_*` 变量），且两次调用 MUST 在服务端完成，API Key MUST NOT 暴露给前端。

#### Scenario: 问答流程包含 Embedding 与 Chat 两次调用

- **WHEN** 已登录用户提交一个有效问题且本班材料中存在匹配分片
- **THEN** 系统先调用 Embedding 接口对问题向量化，再调用 Chat Completions 接口生成回答，两次调用均成功后才返回最终结果

#### Scenario: Embedding 调用失败时问答返回友好错误

- **WHEN** Embedding 服务不可用或返回错误
- **THEN** 问答接口返回 HTTP 503 与「知识库问答暂不可用」类文案，不调用 Chat 接口，不泄露内部服务地址

#### Scenario: Chat 调用失败时问答返回友好错误

- **WHEN** Chat Completions 服务不可用或返回错误
- **THEN** 问答接口返回 HTTP 503 与「知识库问答暂不可用」类文案，不返回任何片段或部分回答，不泄露内部服务地址

### Requirement: 问答回答必须附带可溯源的引用来源

问答接口对每次成功回答 MUST 返回回答文本与一个引用来源列表。每条引用 MUST 至少包含：所属材料的 `document_id`、原始文件名、文件类型、召回的分片文本内容（snippet），以及按文件类型给出的精确位置（PDF 页码 / Markdown 章节路径 / TXT 行号区间）与相似度评分。系统 MUST NOT 返回缺少来源信息或分片文本内容的引用。若召回分片为空（无切片），系统 MUST NOT 调用 Chat Completions 接口，MUST 返回固定句「根据已有材料无法回答该问题」与空引用列表。

#### Scenario: 回答包含文件名、分片内容与精确位置引用

- **WHEN** 问答成功返回回答
- **THEN** 每条引用都同时包含原始文件名、分片文本内容（snippet）与位置字段，且位置与分片元数据一致

#### Scenario: 可凭引用打开本班原文

- **WHEN** 用户在前端点击某条引用的来源徽标
- **THEN** 系统打开 `document_id` 指向的本班材料内容预览；若该材料不属于本班则拒绝访问

#### Scenario: 无召回时不调用生成模型并返回固定句

- **WHEN** 问题在本班材料中没有任何达到召回条件的分片
- **THEN** 接口返回 HTTP 200，系统 MUST NOT 调用 Chat Completions 接口，回答文本为固定句「根据已有材料无法回答该问题」，引用列表为空数组

### Requirement: 前端提供知识问答入口与回答展示

知识库主页面 MUST 在不破坏既有上传、列表、预览、检索布局的前提下提供知识问答入口（输入框与提交）。问答结果 MUST 在页面内容区展示：回答文本以自然语言段落呈现，引用来源以卡片列表展示，每张卡片 MUST 包含原始文件名、分片文本内容（snippet）与页码/章节/行号徽标。点击引用徽标 MUST 能打开对应材料的内容预览。教师与学生使用同一问答入口，可见范围差异完全由服务端班级边界决定。

#### Scenario: 问答结果以回答加引用卡片展示

- **WHEN** 已登录用户输入问题并提交问答
- **THEN** 内容区展示回答文本段落，下方展示引用卡片列表，每张卡片显示原始文件名、分片文本内容（snippet）与页码/章节/行号徽标

#### Scenario: 点击引用打开对应材料

- **WHEN** 用户点击某张引用卡片的来源徽标
- **THEN** 右侧预览打开该 `document_id` 对应的本班材料（PDF 在对应语境下可看到页码提示）

#### Scenario: 学生在前端无法获得外班问答结果

- **WHEN** 学生 A1 与学生 B1 分别提交同一问题
- **THEN** 两人看到的回答与引用分别只基于 A 班与 B 班材料，前端不存在任何可切换班级或扩大问答范围的控件
