## Purpose

定义登录后首页的角色化导航与页面切换契约：教师看到学生名单、本班资料、助手设置与技能管理四个页面，学生看到解题助手对话为主页、资料库为辅、历史会话在侧栏。

## ADDED Requirements

### Requirement: 教师首页为四标签页切换

教师登录后首页 MUST 显示四个标签页：「学生名单」「本班资料」「助手设置」「技能管理」。每个标签页独占右侧主区域全高，切换时 MUST 保持左侧导航不变。标签页 MUST 仅对教师角色可见；学生 MUST NOT 看到任何教师标签页。

#### Scenario: 教师切换四个标签页

- **WHEN** 教师登录后依次点击「学生名单」「本班资料」「助手设置」「技能管理」
- **THEN** 右侧主区域分别显示对应内容，切换时左侧导航保持不变

#### Scenario: 学生看不到教师标签页

- **WHEN** 学生登录后查看首页
- **THEN** 页面不出现「学生名单」「助手设置」「技能管理」标签页或入口

### Requirement: 学生首页为侧栏导航加对话主区

学生登录后首页 MUST 显示左侧导航栏（含「解题助手」「资料库」入口）与右侧主区域。右侧默认显示解题助手对话页（含欢迎语与输入框）。点击「资料库」后右侧切换到本班资料列表。左侧导航下方 MUST 显示历史会话列表，点击可切换到对应会话。

#### Scenario: 学生默认看到解题助手对话页

- **WHEN** 学生登录后进入首页
- **THEN** 右侧默认显示解题助手对话页，含欢迎语与等待输入的聊天框

#### Scenario: 学生切换到资料库

- **WHEN** 学生点击左侧导航的「资料库」
- **THEN** 右侧切换为本班资料列表，左侧导航与历史会话列表保持不变

#### Scenario: 学生从历史会话列表切换会话

- **WHEN** 学生点击左侧历史会话列表中的某条会话
- **THEN** 右侧切换为该会话的对话视图，加载历史消息

### Requirement: 独立知识库检索页与知识问答页不再暴露

前端 MUST NOT 提供独立的知识库检索页面与知识问答页面。后端 `/api/search` 与 `/api/qa` 路由 MUST 保留（解题助手内部 RAG 复用），但前端 MUST NOT 有对应入口或独立视图。

#### Scenario: 首页无检索与问答入口

- **WHEN** 教师或学生登录后浏览首页
- **THEN** 页面上不出现知识库检索输入框、知识问答输入框或对应的独立结果页

### Requirement: 角色可见性由前端与服务端双重保障

前端 MUST 按角色渲染不同的导航与页面入口：教师看到学生名单、助手设置与技能管理；学生仅看到解题助手与资料库。前端控件缺失 MUST NOT 是唯一防线：教师专属接口 MUST 由服务端按角色强制校验，学生调用 MUST 返回 HTTP 403。

#### Scenario: 学生无法访问教师页面与接口

- **WHEN** 学生尝试直接访问教师标签页或调用教师专属接口
- **THEN** 前端不渲染教师入口，直接调接口时服务端返回 403
