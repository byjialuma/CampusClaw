## ADDED Requirements

### Requirement: 教师侧助手配置入口与学生侧不可见性

前端 MUST 为教师提供本班助手的提示词编辑与技能管理入口。入口通过首页标签页呈现：「助手设置」标签页含提示词编辑区与已有技能的启用/停用开关；「技能管理」标签页含技能的新建、上传与删除操作。TutorView 对话视图 MUST NOT 内嵌设置或技能管理标签页——标签页由外层首页导航驱动。

#### Scenario: 教师通过首页标签页访问助手设置与技能管理

- **WHEN** 教师在首页点击「助手设置」或「技能管理」标签页
- **THEN** 右侧显示对应的管理界面，TutorView 对话视图不再内嵌这些标签页

#### Scenario: 学生视图无配置入口但服务端仍拦截

- **WHEN** 学生登录后使用助手页面，并尝试以任何方式调用提示词保存或技能管理接口
- **THEN** 页面不出现相应控件，直接调接口时服务端返回 HTTP 403

## ADDED Requirements

### Requirement: 学生对话页默认显示欢迎语与空态

学生进入解题助手对话页且未选择历史会话时，右侧 MUST 显示欢迎语「解题助手，我帮你」与等待输入的聊天框，引导学生提出第一问。新建会话后空态提示 MUST 保持一致风格。

#### Scenario: 学生首次进入助手对话页

- **WHEN** 学生登录后进入首页，右侧默认为解题助手对话页且无活跃会话
- **THEN** 页面显示欢迎语「解题助手，我帮你」与等待输入的聊天框
