## ADDED Requirements

### Requirement: 教师可登记本班 MCP 服务器且令牌不回传

系统 MUST 为教师提供登记本班 MCP 服务器的能力：填写服务器名称与 Base URL，并可选填写 Bearer 令牌。服务器归属班级 MUST 取自登录会话（JWT claims），MUST NOT 采用请求参数中的班级标识。同一班级内服务器名称 MUST 唯一，重名登记 MUST 返回 HTTP 400。Bearer 令牌 MUST 只保存在服务端，MUST NOT 出现在任何接口响应、日志或前端代码中；读取服务器列表的响应 MUST 只以布尔值表示「是否已配置令牌」。登记、修改与删除接口 MUST 仅对教师角色开放，未登录调用 MUST 返回 401，学生调用 MUST 返回 403，跨班或不存在服务器的访问 MUST 返回 404。服务器名称 MUST 可作为 MCP 引用的服务器段使用（小写字母开头，允许字母、数字、下划线与连字符）。

#### Scenario: 登记成功且响应不含令牌

- **WHEN** 教师填写名称、Base URL 与令牌登记一台服务器
- **THEN** 服务端返回成功，响应中只出现表示已配置令牌的布尔字段，不出现令牌字段或其原文

#### Scenario: 同班重名登记被拒绝

- **WHEN** 教师在同一班级再次登记与已有服务器同名的服务器
- **THEN** 系统返回 HTTP 400，原有服务器保持不变

#### Scenario: 未登录与学生登记被拒绝

- **WHEN** 未携带有效令牌调用登记接口，或已登录学生调用登记接口
- **THEN** 前者返回 HTTP 401，后者返回 HTTP 403，均不写入任何服务器

#### Scenario: 跨班访问他班服务器返回不存在

- **WHEN** 教师尝试修改或删除不属于本班的服务器
- **THEN** 系统返回 HTTP 404，且不透露该服务器是否存在

### Requirement: 连接服务器完成握手与工具发现，断开即清空清单

教师对某台已登记服务器发起连接时，系统 MUST 先按 MCP 协议与该服务器完成握手，再执行工具发现，把发现的工具清单缓存到本系统，随后将该服务器标记为已连接。连接过程中任一步失败时，系统 MUST 返回 HTTP 502 与可读错误提示，MUST 保持该服务器为未连接状态，MUST NOT 写入部分工具清单；连接失败 MUST NOT 影响既有知识库检索与流式对话主路径的可用性。教师发起断开时，系统 MUST 将该服务器标记为未连接并清空其工具清单，之后该服务器上的工具 MUST NOT 再被调用。连接、断开与工具发现接口 MUST 仅对教师角色开放。

#### Scenario: 连接成功并缓存工具清单

- **WHEN** 教师对一台已登记的可用服务器发起连接
- **THEN** 系统完成握手与工具发现，返回该服务器上的工具名称清单并缓存，服务器状态变为已连接

#### Scenario: 地址或令牌错误返回可读错误

- **WHEN** 教师对 Base URL 不可达或令牌错误的服务器发起连接
- **THEN** 系统返回 HTTP 502 与可读错误提示，该服务器仍为未连接且无工具清单

#### Scenario: 断开后清单清空

- **WHEN** 教师对已连接的服务器发起断开
- **THEN** 系统将其标记为未连接并清空缓存的工具清单，随后界面与该服务器记录中不再显示任何已发现工具

#### Scenario: 连接失败不影响检索与对话

- **WHEN** 某台服务器连接失败，随后学生正常提问
- **THEN** 本班知识库检索与流式回答仍按既有行为正常工作

### Requirement: 技能工具栏支持 MCP 引用且保存前逐条校验

技能正文中的「工具」行 MUST 被解析为工具引用列表：该行以「工具」开头，后接冒号，值以逗号分隔，每项为内置引用 `knowledge_search` 或 MCP 引用 `工具名@服务器名`。系统 MUST 在在线新建技能与上传技能文件（md/txt）两条路径上使用同一解析与校验：对每个 MCP 引用逐条校验服务器在本班已登记、服务器处于已连接状态、且该工具出现在该服务器缓存的工具清单中；任一条件不成立时 MUST 拒绝保存并返回可读的拒绝原因（指明具体引用），MUST NOT 写入该技能。内置引用 `knowledge_search` MUST 无需 MCP 校验即被接受。解析出的工具引用 MUST 可在技能管理界面查看。

#### Scenario: 合法引用保存成功

- **WHEN** 教师新建技能，其「工具」行包含一台已连接服务器缓存清单中存在的 `工具名@服务器名`
- **THEN** 技能保存成功，技能列表中可看到该工具引用

#### Scenario: 工具不在清单中拒绝保存

- **WHEN** 技能「工具」行引用的工具名不在该服务器缓存的工具清单中
- **THEN** 系统拒绝保存并返回可读拒绝原因，技能未被写入

#### Scenario: 服务器未连接拒绝保存

- **WHEN** 技能「工具」行引用的服务器在本班已登记但处于未连接状态
- **THEN** 系统拒绝保存并返回可读拒绝原因，技能未被写入

#### Scenario: 服务器不存在拒绝保存

- **WHEN** 技能「工具」行引用的服务器名在本班不存在（含已被删除）
- **THEN** 系统拒绝保存并返回可读拒绝原因，技能未被写入

#### Scenario: 内置引用无需校验

- **WHEN** 技能「工具」行只包含 `knowledge_search`
- **THEN** 系统直接接受并保存，不做任何 MCP 校验

#### Scenario: 上传技能文件走同一校验

- **WHEN** 教师上传一份「工具」行含非法 MCP 引用的 md 或 txt 技能文件
- **THEN** 系统按与在线新建相同的规则拒绝保存并返回可读拒绝原因

### Requirement: 提问命中技能时服务端带令牌调用远端工具

学生提问时，系统 MUST 在生成回答前为本轮已启用技能解析工具引用：内置引用 `knowledge_search` 沿用既有本班检索（始终执行，行为不变）；MCP 引用则按其所属服务器缓存清单与令牌调用远端 `tools/call`。若某技能正文声明了「适用条件」行（值以逗号分隔的关键词），则该技能声明的 MCP 工具仅当问题文本包含其中至少一个关键词时才被调用；未声明该行时，技能启用即调用其声明的 MCP 工具。同一轮内同一工具引用 MUST NOT 重复调用。远端调用的结果文本 MUST 作为数据拼入该轮用户消息的上下文，并 MUST 明确标注为工具返回的数据而非系统指令，MUST NOT 改写系统提示词；持久化的用户消息内容 MUST 仍为学生的原始问题。远端调用 MUST 受超时上限约束，超时或远端报错时 MUST 记为出错状态并继续生成回答，MUST NOT 使整轮回答失败。当引用的服务器未处于已连接状态、工具不在其缓存清单中、或该服务器在本班已不存在时，系统 MUST 记为拒绝状态，MUST NOT 发起远端调用，MUST NOT 静默当作成功。

#### Scenario: 命中技能即带令牌调用且回答体现工具结果

- **WHEN** 教师启用含 `formula_hint@campus-tools` 引用的技能，学生就该技能可识别的主题提问
- **THEN** 服务端带令牌调用远端工具，回答内容体现工具返回的信息

#### Scenario: 调用结果作为数据注入而非系统指令

- **WHEN** 远端工具返回的文本中包含类似指令的语句
- **THEN** 该文本仅作为用户消息中的数据被送入模型，系统提示词与角色约束不受其影响

#### Scenario: 持久化的用户消息仍为原始问题

- **WHEN** 学生提问并触发了工具调用
- **THEN** 该会话中该轮用户消息的持久化内容仍是学生的原始问题

#### Scenario: 同一引用同一轮只调用一次

- **WHEN** 多条已启用技能声明了同一 `工具名@服务器名` 引用
- **THEN** 该轮内该引用只被远端调用一次

#### Scenario: 声明适用条件时未命中关键词则不调用

- **WHEN** 技能声明的「适用条件」关键词均未出现在学生问题中
- **THEN** 服务端不调用该技能声明的 MCP 工具，本轮工具调用列表中不含该引用

#### Scenario: 远端超时或报错仍生成回答

- **WHEN** 远端工具调用超时或返回错误
- **THEN** 该引用被记为出错状态，系统继续生成并返回回答，学生仍能收到回答

#### Scenario: 未连接服务器的工具调用记为拒绝

- **WHEN** 技能引用的服务器处于未连接状态，学生提问命中该技能
- **THEN** 该引用被记为拒绝状态，未发起远端调用，且不表现为成功

#### Scenario: 已删除服务器的工具调用记为拒绝且无审计行

- **WHEN** 技能引用的服务器在本班已被删除，学生提问命中该技能
- **THEN** 该引用在响应中记为拒绝状态，且不产生审计记录

### Requirement: SSE meta 事件暴露本轮工具调用状态

流式回答开始前的 meta 事件 MUST 携带本轮工具调用列表，每项 MUST 含工具引用与状态，并在失败时含失败原因；对 MCP 引用 MUST 含服务器名。状态 MUST 取值为成功、拒绝、出错三者之一。meta MUST NOT 返回任何令牌、远端内部地址或工具返回的完整原文。

#### Scenario: 命中工具时 meta 含该引用与成功状态

- **WHEN** 学生提问命中带 MCP 工具的技能且远端调用成功
- **THEN** meta 事件携带该工具引用且状态为成功

#### Scenario: 越权或未连接时 meta 中该引用为拒绝

- **WHEN** 技能引用的服务器未连接或已被删除，学生提问命中该技能
- **THEN** meta 事件中该引用状态为拒绝

#### Scenario: meta 不含令牌与内部地址

- **WHEN** 学生提问触发工具调用
- **THEN** meta 事件中不出现任何 Bearer 令牌或远端服务内部地址

### Requirement: 工具调用写入本班审计且教师可查

每一次对远端工具的调用尝试 MUST 写入审计记录，含工具引用、服务器名、状态、发起学生、所属班级、会话标识与发生时间；唯一例外是该引用所属服务器在本班已被删除，此时调用当即被记为拒绝且 MUST NOT 产生审计记录。审计记录 MUST 按班级隔离。教师 MUST 能查看本班最近的调用记录；审计接口 MUST 仅对教师开放，未登录调用 MUST 返回 401，学生调用 MUST 返回 403，跨班访问 MUST NOT 返回他班记录。

#### Scenario: 成功拒绝出错各写入一条审计

- **WHEN** 分别发生一次成功的工具调用、一次未连接导致的拒绝、一次远端报错
- **THEN** 审计中出现三条对应记录，各自状态为成功、拒绝、出错

#### Scenario: 教师可查本班审计记录

- **WHEN** 教师请求本班调用记录
- **THEN** 返回的记录含工具引用、服务器名、状态、发起学生与时间

#### Scenario: 学生无权查看审计

- **WHEN** 学生请求调用记录接口
- **THEN** 系统返回 HTTP 403，不返回任何记录

#### Scenario: 跨班不返回他班审计记录

- **WHEN** 教师请求他班班级的调用记录
- **THEN** 系统不返回任何他班记录

### Requirement: 教师侧 MCP 管理界面且学生不可见

前端 MUST 为教师提供本班 MCP 服务器管理入口：登记（名称、Base URL、令牌）、修改、删除、连接与断开、查看已发现的工具清单、查看最近调用记录；技能管理界面 MUST 展示每条技能解析出的工具引用，并在保存被拒时展示可读的拒绝原因。学生视图 MUST NOT 出现任何 MCP 服务器、工具清单或调用记录的入口，学生 MUST NOT 能登记、修改、连接或断开采服务器。前端控件缺失 MUST NOT 是唯一防线：全部 MCP 管理接口 MUST 由服务端按角色强制校验。

#### Scenario: 教师可完成登记、连接与查看工具

- **WHEN** 教师在管理界面登记一台服务器并点击连接
- **THEN** 界面显示连接成功与已发现的工具名清单，并可查看最近调用记录

#### Scenario: 学生界面无 MCP 入口且接口被拒

- **WHEN** 学生登录后浏览首页，并尝试直接调用 MCP 管理接口
- **THEN** 页面不出现任何 MCP 管理控件，接口调用返回 HTTP 403
