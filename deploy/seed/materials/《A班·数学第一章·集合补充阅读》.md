## 子集与真子集

- 若集合 A 的任意一个元素都是集合 B 的元素，则称 **A 是 B 的子集**，记作 A ⊆ B。
- 若 A ⊆ B 且 B 中至少有一个元素不属于 A，则称 **A 是 B 的真子集**。

## 区间表示

| 集合表示 | 区间 |
| --- | --- |
| a ≤ x ≤ b | [a, b] |
| a < x < b | (a, b) |
| a ≤ x < b | [a, b) |
